## 📋 Topics Covered

- **AI**
- **Generative AI**
- **LLMs** (e.g., OpenAI, Gemini, Claude, Grok)
- **GPTs** (Generative Pre-trained Transformer)
- **RAGs** (Retrieval-Augmented Generation)
- **Protocols** (e.g., MCP, A2A), MCP Servers
- **AI Workflows / Frameworks**
- **Agentic AI**
- **AI Agents**
- **Multi-Agent Workflows / Orchestration**

## 🎯 Purpose

This repository is a documentation hub — a single place to collect notes, explainers, and reference material spanning the AI landscape, from foundational concepts through to agentic, multi-agent systems. It's meant to be a knowledge base you can point to, rather than a codebase you run.

## 🧭 How It's Organized

Documents are grouped by the topic areas listed above. As the collection grows, each topic will hold its own set of write-ups covering core concepts, comparisons (e.g., across LLM providers), and practical guidance for applying them.

## 👥 Who This Is For

- Engineers and architects building a working mental model of the AI stack
- Anyone comparing LLM providers, protocols, or agentic frameworks
- Teams looking for a shared reference on RAG, MCP, and multi-agent orchestration concepts

## 🤝 Contributing & Feedback

This is a living documentation set, updated as the field moves. If you spot something outdated, want to suggest a topic, or have a resource worth adding, open an issue or reach out directly.
